# DrugAlpha · Codex 插件

[English](README.md) · 简体中文

通过 `https://drugalpha.com/mcp` 只读查询 **DrugAlpha 创新药数据库**的管线、催化剂、临床、竞争格局、销售、估值、中国/美国费用与专利、技术分析及已开放 Excel。分析由用户自己的 AI 完成。

参见[仓库说明](../../README.zh-CN.md)、[安装指引](../../INSTALL-AGENT.zh-CN.md)和[查询示例](../../QUERY-GUIDE.zh-CN.md)。实际以账号权限及已发布覆盖为准。

使用客户端支持的浏览器授权或个人 Key 凭据设置。专用 Key 框只填 Key；完整 Authorization 请求头才填 `Bearer <你的个人Key>`。不分享凭据；普通更新先刷新工具，保留正常 OAuth 连接。默认按问题语言回答。
