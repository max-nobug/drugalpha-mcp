## 如何连接

### 让 AI 帮你配置

> 请帮我连接 DrugAlpha 创新药数据库 MCP。先阅读本仓库 README.zh-CN.md 和 INSTALL-AGENT.zh-CN.md，保留已有客户端设置，由我在浏览器完成登录授权；然后查询胰腺癌一线治疗竞争格局，验证实际查询成功。

[安装指引](INSTALL-AGENT.zh-CN.md) · [下载中英双语接入 ZIP](https://github.com/max-nobug/drugalpha-mcp/raw/refs/heads/main/downloads/drugalpha-mcp-v0.2.zip)

### 浏览器 OAuth 授权

客户端需支持远程 HTTP MCP 和 DrugAlpha 浏览器授权。入口随客户端版本、账号及套餐变化；添加本仓库不代表已被任何客户端官方市场收录。

- **WorkBuddy：**在连接器设置中新增自定义 MCP。此前验证的 5.7.7 入口为“专家·技能·连接器 → 连接器 → 自定义连接器 → 添加 MCP”；只合并 DrugAlpha 项，启用后完成浏览器授权。
- **ChatGPT：**从账号可用的应用或自定义连接入口添加服务地址，在浏览器授权，然后在对话中选择 DrugAlpha。入口是否开放以当前客户端和套餐为准。
- **Codex：**支持插件目录的版本可运行 `codex plugin marketplace add max-nobug/drugalpha-mcp`，安装 DrugAlpha 后授权。手动配置可参考 `codex.toml`，合并前核对当前版本支持的字段。
- **Claude Code：**使用其当前支持的插件/MCP 安装及授权入口，插件目录为 `plugins/drugalpha-claude`；具体命令以已安装客户端帮助为准。

支持 JSON 配置的客户端可参考以下内容，字段以客户端实际支持为准：

```json
{
  "mcpServers": {
    "drugalpha": {
      "type": "http",
      "url": "https://drugalpha.com/mcp",
      "timeout": 60000,
      "disabled": false
    }
  }
}
```

保留其他服务和已有正常连接。普通更新先刷新工具列表或开启新会话，确需重新授权时再按客户端提示操作；浏览器授权成功与实际查询成功需分别确认。

### 个人 Key：Alpha 派、AlphaEngine 等客户端

个人 Key **已开放**。登录自己的账号，在[个人 Key 管理](https://drugalpha.com/oauth/keys)中命名创建，例如“Alpha 派”或“AlphaEngine”。完整 Key 仅创建时显示，请直接复制到可信客户端的凭据设置。

| 配置项 | 填写内容 |
| --- | --- |
| 服务地址 | `https://drugalpha.com/mcp` |
| 客户端专用 Key 输入框 | 只粘贴 **Key 本身，不带 Bearer** |
| 手工配置完整请求头 | 请求头名称 `Authorization`，内容 `Bearer <你的个人Key>` |

专用 Key 输入框可能由客户端自动添加前缀，不要重复填写 Bearer。[主站图文说明](https://drugalpha.com/connect-ai)提供 Alpha 派、AlphaEngine 的接入步骤；连接技能后，按客户端要求将它添加或选择到聊天中。

Key 有效期跟随订阅，续订后未撤销的 Key 可继续使用；已撤销的不恢复。Key 与 OAuth 可以同时使用，沿用账号数据权限、分别撤销互不影响，访问记录统一计入账号。不要把真实 Key、密码、Cookie 或令牌发到聊天、Issues、示例或公开文件中。

## 治疗费用与专利：先区分市场

- **中国市场治疗费用：**获取中国说明书和药价，使用费用框架，明确确认剂量、频率、疗程和价格口径；与美国服务端费用测算不同。
- **美国市场治疗费用：**先选定产品和包装、查看说明书方案，再确认适应症、剂量、频率和疗程，必要时补充体重或体表面积。正式计算采用已核实包装计价的得州年度 WAC；价格缺失或计价未核实则说明缺口，不让 AI 编造。年度 WAC 不等于实时成交价或患者自付费用。
- **专利到期：**明确中国或美国，保留具体产品、专利/独占期类别、来源和日期。无匹配记录不等于不存在专利保护。

## Excel 领取

账号具备相应工具权限时，可领取板块估值和板块持仓 Excel。行业 PS 趋势、公司 PS 对比导出沿用平台导出权限，包括适用的管理员要求，具体以当前工具列表为准。海外销售尚无独立 MCP Excel 下载工具。

临时授权文件引用不是公开分享链接，实际读取或保存成功后才能声称已交付。

## 语言、口径与数据使用

支持用中文或英文提问，默认按问题语言回答，也可指定输出语言。名称匹配以已覆盖名称与别名为准，有歧义先确认，不擅自更换公司、药物或人群。

保留来源、日期、单位、币种、财年、人群和覆盖缺口。缺失不填零、预测不当实际值，管线记录不等于独立药物；财报合列金额不拆分，重叠地区不重复相加。读取公告正文后才能声称已读公告。完整 DCF 生成、平台 AI 自动生成和业务数据写入不属于当前连接器开放范围。

请遵守 DrugAlpha 服务协议，用于正常研究，禁止整库复制、镜像和转售。实际第三方请求可能受上游保护限流，本地或缓存读取与实际外部请求分别处理；账号与订阅权限、额度仍适用。

在 [Issues](https://github.com/max-nobug/drugalpha-mcp/issues) 反馈客户端版本、操作步骤和脱敏错误。本仓库只提供公开接入资料与客户端插件，不分发服务端。Registry 登记元数据单独维护，见[登记说明](REGISTRY.md)。
